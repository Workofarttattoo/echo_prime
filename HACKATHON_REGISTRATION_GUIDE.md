### What to Build (48 hours)

**Project: "Echo Math Tutor - AI That Shows Its Work"**

**Elevator Pitch:**
"Most AI tutors (like ChatGPT) just give answers. Students copy without learning. Echo explains step-by-step, teaching the problem-solving process."

**Demo Flow (5 minutes):**

1. **Problem Setup** (30 seconds)
   - Student types: "What is 15 * 8?"
   - GPT-4 shows: "120"
   - Echo shows:
     ```
     15 × 8 = 120
     
     Step 1: Identified multiplication problem
     Step 2: Computed 15 × 8 using symbolic math engine
     Step 3: Result: 120
     
     Method: Deterministic symbolic calculation (100% accurate)
     ```

2. **Complex Problem** (1 minute)
   - Student: "If a train travels 60 mph for 2.5 hours, how far does it go?"
   - Echo shows:
     ```
     Distance = Speed × Time
     Distance = 60 mph × 2.5 hours
     Distance = 150 miles
     
     Step-by-step:
     1. Identified word problem: distance = speed × time
     2. Extracted values: speed = 60 mph, time = 2.5 hours
     3. Calculated: 60 × 2.5 = 150
     4. Answer: 150 miles
     
     Method: Symbolic math engine with word problem parser
     ```

3. **Learning Impact** (1 minute)
   - Show side-by-side: Student using ChatGPT vs Echo
   - ChatGPT: Gets answer, doesn't learn process
   - Echo: Sees reasoning, learns method, can apply to new problems

4. **Explainability Rating** (1 minute)
   - Show human evaluation: Echo 4.5/5, GPT-4 2.3/5
   - Teacher testimonial: "Finally an AI that teaches, not just answers"

5. **Vision** (1.5 minutes)
   - Scale to all subjects: math, physics, chemistry, coding
   - Integration: Canvas, Google Classroom, Khan Academy
   - Impact: 10M+ students learn problem-solving, not just memorization

**Technical Implementation:**
- Use existing Echo codebase
- Build simple web interface (Flask or Streamlit)
- Demo on laptop (no cloud needed)
- Have backup video if demo fails
