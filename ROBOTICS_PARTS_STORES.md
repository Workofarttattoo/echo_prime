## 🛒 SHOPPING STRATEGY

### For Beginners (Just Starting)

**Step 1:** Buy a starter kit
- Option A: Arduino Starter Kit ($50-$100) from Amazon/Arduino.cc
- Option B: Complete robot kit (SunFounder Robot Car V4, ~$80-$120)

**Step 2:** Join SYN Shop
- Visit 2x free
- Get membership (~$50-$100/month typically)
- Access tools + community

**Step 3:** Build first project
- Follow kit tutorials
- Attend Monday robot nights at SYN Shop
- Learn from community

---

### For Intermediate (Some Experience)

**Best Sources:**
1. Pololu (local, 920 Pilot Rd) - motors, chassis, sensors
2. Adafruit + SparkFun (online) - unique sensors, breakout boards
3. Amazon (fast shipping) - common components
4. SYN Shop membership - access to tools

**Build Strategy:**
- Design robot on paper first
- Order specific components from Pololu/Adafruit
- Use SYN Shop tools (3D print parts, laser cut chassis)
- Test and iterate

---

### For Advanced (Serious Projects)

**Pro Sources:**
1. Pololu - precision motors, encoders, advanced sensors
2. RobotShop - professional components
3. Digikey / Mouser - electronic components (capacitors, resistors, ICs)
4. McMaster-Carr - mechanical parts (screws, bearings, aluminum stock)

**Development Strategy:**
- CAD design (Fusion 360, SolidWorks)
- 3D print/CNC at SYN Shop
- Source components from multiple vendors
- Consider custom PCB (OSH Park, JLCPCB)
